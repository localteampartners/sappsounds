# sappsounds

<!-- UPDATE WHEN: the one-line description changes, or the repo's top-level layout changes -->

Framework-independent C++20 sample-instrument engine: SFZ parsing, immutable instrument definitions, region selection, sample decoding, caching, resampling, and realtime-safe sample-voice playback. Reusable static library (CMake target SappSounds, namespace sapp::sounds) consumed by SappOrchestra and future Sapp instruments.

**Live status:** [monitor.sapplab.net/projects/sappsounds](https://monitor.sapplab.net/projects/sappsounds)
